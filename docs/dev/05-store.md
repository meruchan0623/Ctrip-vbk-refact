# 05 最小状态与提醒恢复

2026-10-30。只为当前网页 IM 与独立强提醒保存必要状态，不重建桌面客户端完整数据库。

网页自身的消息存储沿用目标网页行为；若本地重写 IM，缓存和草稿按网页功能实际需要设计。新增提醒状态最小包括身份代次、会话 ID、等待 round/version、可确认的起始消息与时间、已提醒版本和用户隐藏版本。

存储数据按身份隔离；事务提交后才能发布本地新快照。去重键至少含身份与上游消息作用域，不将本地展示序号冒充服务端游标。未知发送结果保留，不能因重启变成待重发。

重启读取的是待核对状态，不能直接弹窗/补响。服务端补偿与会话回读完成后才恢复当前轮次。注销使旧身份状态不可操作，凭据与客户正文不进入诊断日志。

本轮不安排旧 Electron 库导入、全文检索引擎、通用数据库浏览器、全量备份/恢复产品流程。实现细节与存储引擎在原型后确定，避免先造一套旧表结构。旧设计见[归档](../archive/desktop-baseline/dev/05-store.md)。

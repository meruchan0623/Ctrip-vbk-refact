# 01 最小宿主与窗口

2026-10-30。只服务[当前范围](../decisions/2026-10-30-web-only-scope.md)。

主窗口 `main` 承载消息、通知、网页个人设置与订单联系流程；`alarm` 是唯一额外的独立窗口。首次需要时创建并复用 alarm，不按每条消息创建窗口。

- 主窗口隐藏/最小化不停止已连通的消息处理与本地计时；系统睡眠期间不承诺运行，恢复先对账。
- alarm 显示时置顶但不抢焦点；用户主动点“打开会话”才激活主界面。窗口位置约束在可用显示器内。
- 注销、身份替换与进程退出撤销事件订阅并清除对应窗口数据；关闭 alarm 仅暂时隐藏当前提醒，不结束客户等待。
- 新标签只处理登录和已验证的订单/IM 联系目标，校验 HTTPS 来源与当前身份；未知深链不自动取得会话权限。
- 不增加托盘预览、任务栏数字、多账号桌面标签、通用网页工作台、全局截图快捷键和自启设置等产品功能。

Tauri/WebView2 的置顶、不激活显示、焦点与 DPI 必须先做原型；文档未给出实测通过承诺。完整设计见[强提醒](03-strong-alert.md)，旧窗口盘点见[历史归档](../archive/desktop-baseline/dev/01-shell.md)。

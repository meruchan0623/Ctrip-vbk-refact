# 08 必要偏好与本地诊断

2026-10-30。只处理目标网页开放的设置，以及独立强提醒所需的本地开启、阈值和单次声音开关。

本地新增偏好须明确标为本项目强提醒设置，不映射成不存在的携程后端设置接口。业务设置按目标网页已有请求保存，成功读回后更新展示；失败不伪装成功。

诊断仅记录连接状态、消息序号缺口、补偿完成情况、提醒轮次转换、窗口显示结果及必要错误码；不记录 Cookie、token、客户正文或完整业务标识。不能把本地诊断当作平台埋点接入授权。

不实现自动更新产品服务、携程 CDN 分配、旧客户端自动迁移、云端崩溃上报、外部遥测或通用设置中心。可运行原型与最终安装交付的必要签名/权限检查在实际选定平台完成，不恢复旧更新模块。

旧方案见[归档](../archive/desktop-baseline/dev/08-update-telemetry.md)。

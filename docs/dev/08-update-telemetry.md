# 08 更新、偏好与诊断

2026-10-30。本项目自有能力，保留。

- 客户端更新：签名校验的更新包与更新策略，本项目受控发布源；下载、校验、重启/退出时安装。
- 偏好：通用、显示、通知与提醒（含强提醒开关/阈值/声音）、快捷键、商家助手、网络、存储、隐私。网页已有的个人业务设置（个人资料、上班时间、快捷回复、自动答复、自动翻译）走网页接口并回读，不与本地偏好混用。
- 本地诊断包：脱敏日志与环境信息，默认不含聊天正文与凭据；云端崩溃/埋点上报须确认接收端授权后再开启。

2026-10-30 落盘：设置窗口 `vbk/ui/apps/setting` 已实现“通知与提醒”（开关、T1 30/60/90/120/180、超时音、L4 默认关、弹出位置、勿扰及“勿扰时仍提醒回复超时”、全屏、托盘闪烁、任务栏数字）与“商家助手”发送模式说明；其余分区为真实开关占位经 `prefs_set` 持久化。客户端更新、诊断包、崩溃观察未实现；`update` 窗口只有最小 capability。

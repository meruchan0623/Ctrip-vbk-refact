# 09 商家助手

保留能力涉及的 TSim 完整方法、Header/Bearer、编码、翻译字段与套餐调用链见[TSim 接口源码契约](../api/external-tsim.md)。这份契约已与当前客户端和拥有方源码对照，线上兼容验证单独标注，不把静态来源当作实测。

2026-10-30。本项目自有能力，保留。

- TSim 登录（不保存密码，凭据存系统凭据库）。
- 翻译服务统一为：**出站（商家 → 客户）固定使用 TSim**，需先登录 TSim；**入站（客户 → 商家）固定使用平台官方翻译**，译文显示在客户原文下方。不提供翻译服务切换。
- 出站翻译：外语会话输入中文后约 0.5 秒生成 TSim 译文预览；客户语言自动识别，可手动改目标语言。
- 发送模式（设置中二选一，界面上需带说明）：
  - **替换草稿**（默认）：译文先在翻译栏预览，点「替换」把输入框内容换成译文，可再修改后手动发送。适合需要核对译文的场景。
  - **直接发送**：按发送键时自动把中文用 TSim 译成客户语言并发出，客户只收到译文，消息下方保留原文供自己核对。适合熟练、追求速度的场景。
  - 两种模式下，译文都绑定会话与草稿版本；草稿改动后需重新翻译，翻译失败时提示「发送原文 / 重试」，不静默发送原文。
- 套餐速览：按消息中的 ICCID/EID 查询套餐、剩余量、供应商/APN、流水号，60 秒内复用结果；右侧栏与订单信息并列显示。
- 订单查询面板（TSim）。

均为本项目接入的外部服务，不冒充携程网页能力。详细设计沿用[归档正文](../archive/desktop-baseline/dev/09-assistant.md)。

2026-10-30 落盘：`vbk/crates/core-assistant` 按 [TSim 契约](../api/external-tsim.md) 实现登录（multipart、不记录密码）/profile/刷新（JWT exp 前 5 分钟，不可读则 30 分钟）/登出请求与解析、出站翻译严格六字段与回显校验、译文绑定账号/会话/草稿版本、替换草稿/直接发送状态机（失败只提示“发送原文 / 重试”，不静默发原文）、套餐查询链与 60 秒缓存、ICCID/EID 识别、语言建议；入站翻译在适配器 `translation.ts` 调平台 `batchTranslateByMsgIds`。界面有翻译栏与套餐速览槽位。TSim 线上兼容、真实 token 与套餐 scope 未动态核验；HTTP 发送由宿主承担，尚未接线。

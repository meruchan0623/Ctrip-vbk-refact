# 会话列表产品名称预加载与缓存

进入账号会话列表后，按列表消息时间顺序串行读取官方 getVbkImUserinfo 的产品来源，每次仅一条。结果逐条合入 ConversationStore 并发布会话展示，不依赖打开聊天，不读取聊天分页，也不发送已读回执。

持久缓存位于客户端账号 WebView 的本地存储，命名空间含环境和账号，条目键另含 gid、sessionId、客户、业务类型、thread、会话键、工单和订单。仅保存产品名、订单ID和缓存时间，不保存完整接口响应、联系人或消息。最多1000项。账号 WebView 使用稳定的 WKWebView data_store_identifier / Windows data_directory，因此使用其持久存储能力；本轮仅验证了存储适配器的重建恢复，未进行真实桌面重启验收。

列表投影先恢复可匹配的缓存；15分钟内复用缓存，过期后后台串行刷新且刷新期间保留已有名称。失败至少60秒后才重试；明确无来源或权限拒绝时移除当前缓存。会话身份变化、账号停止、列表移除后的旧结果不得更新名称或持久缓存。打开聊天的前台来源读取可通过 sourceRead 序号覆盖后台请求。

验证：3项专项覆盖串行与逐条显示、重新创建会话后缓存恢复、账号隔离、停止后的延迟结果丢弃及旧服务结果不污染缓存。类型检查和UI/适配器bundle通过。全量运行当时1331项中1330通过、1项reopen-send.test.ts“处理中的会话不读回也不重开”失败；单独运行该直接RPC测试可重现额外请求，与本次新增session预加载路径没有直接调用关系，未改动该发送流程来迁就断言。日志：/tmp/vbk-product-name-tests.log。未打包桌面安装包或发布。

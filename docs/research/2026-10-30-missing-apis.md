# 缺失接口复查与网页版范围收敛

2026-10-30，Asia/Singapore。本篇覆盖原“未找到的接口清单”的后续处理。用户现已明确：**不再跟随桌面客户端，只做网页版已有的消息、通知和按订单号打开客户会话；网页版没有的功能全部不做。** 详细边界见[范围决定](../decisions/2026-10-30-web-only-scope.md)。

本轮先尝试电脑操作连接桌面应用，但连接超时/存在同 bundle ID 副本，未通过该工具点击到原生窗口。随后使用 `ego-browser` 操作真实已登录网页；用户进一步指定网页版为唯一业务依据，此后不再追查桌面入口。未手动发消息、结束/转移会话或修改提醒设置；打开会话可能创建/激活会话，进入通知分类会触发官方标读。

## 二、原清单逐项处置

保留原编号以便历史引用；“移除”表示不再是开发阻塞项，不表示接口不存在。

| 原编号 | 项目 | 当前处理 |

| 2 | 置顶、星标、跨设备同步 | 拆开：星标写接口已定位，置顶本地，跨设备同步未证实，不新增该承诺 |

## 三、仍需核实的网页行为

| 问题 | 当前边界 |
| --- | --- |
| 上线、挂起、离开、下班的分配规则 | 按网页工作状态接口接入，不从名称推定自动转接、停分配或恢复时长 |
| 欢迎语/离开语/非工作时间语由哪端发送 | 只保留网页开放的设置和已证实行为；未验证前不在新客户端额外自动发送 |
| 有效订单侧栏详情 | 订单详情网页可打开，不等于 `14735/getOrderDetailsForVbk` 已返回有效 `orderInfoDto`，两条契约分开 |
| 星标、评价、结束、转移、发送失败的状态收敛 | 本轮未执行这些业务写操作验证；已定位接口须在相应网页入口和授权样本中验收 |
| 后台提醒和音频权限 | 浏览器影响后台调度、通知展示与自动播放，不承诺与原生桌面强窗相同 |

## 四、后续探查顺序

只补消息、通知和订单联系入口的必要证据，不再遍历事件、公告、商服、工作台或数据。优先补：订单无结果/多结果/无权限、已有会话与新发起分支；消息回执与断线补偿；网页已提供的星标/评价/结束及失败读回。不能因为旧文档保留任务编号就恢复取消的功能。

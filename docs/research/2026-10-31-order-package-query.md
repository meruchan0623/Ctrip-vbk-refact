# 当前会话订单的全部套餐与本地详情

原侧栏只尝试从消息取ICCID，不能按会话订单自动查询，也不能打开对应的TSim详情。本块以官方适配器的完整会话身份代次和有效订单号为准，自动读取订单套餐列表，保留每份套餐，并用宿主签发的句柄打开本地只读详情。没有关联订单时保留ICCID后备；没有用量字段时显示待查询。

查询前后都校验账号、环境、登录代次、客户与服务会话代次、订单及TSim会话代次。普通未读数、备注和资料更新不会触发重复查询或清空有效详情；真正身份缺失及恢复也不能复活旧句柄。失效的详情再次打开会创建新窗口实例，旧窗口关闭回调不能撤销新实例。每窗只允许读取其绑定套餐及最小窗口操作，不接受前端提供card ID、任意URL或认证数据。

契约、资源上限、缺失字段及静态来源见 [external-tsim](../api/external-tsim.md)。真实接口依次为perform/list，用户打开某套餐后再读取detail/live/CDR。补充接口空投影只表示未返回可显示的数据；不证明实际没有用量。

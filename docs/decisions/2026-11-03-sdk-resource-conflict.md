# X11：同账号不支持客户端与官方网页并用

2026-11-03，用户在本轮最终实现审查中明确选择：**不要求同时在线，被踢时明确提示即可**。

## 产品约束

- 同一携程账号不承诺新客户端和官方浏览器网页同时在线。不同账号的隔离与并行使用仍在范围内。
- SDK 明确报告账号被踢、身份失效或资源冲突等终态时，停止本会话自动重连/重建，不反复抢占账号。
- 主界面显示“账号可能已在其他位置登录，请重新登录”，并保留本地草稿及未知发送记录；重登由用户发起。
- 未识别的普通网络故障不能猜成被踢，仍按网络恢复策略处理；只有有证据的终态才能终止恢复。

## 验收影响

解除 I-05b 的 X11 产品选择未决项；不再要求同账号客户端+官方网页并用一小时持续在线。不等于传输监督已接线，不等于已证明具体 SDK 冲突根因或终态识别正确。

仍必须验证：终态后零自动重连、无重连风暴、清楚的登录反馈、用户重登恢复、不同账号互不影响、普通断网恢复及 72 小时长稳。实现/实际目标包证据另记。

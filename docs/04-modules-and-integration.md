# 当前模块与联动

2026-10-30。唯一产品扩展为独立强提醒，完整约束见[范围决定](decisions/2026-10-30-web-only-scope.md)。

| 职责 | 输入 → 输出 |
| --- | --- |
| 网页 IM 适配 | 当前网页身份、消息/会话与回执 → 带身份代次的结构化事实 |
| 消息与通知界面 | 网页既有交互 → 已验证业务调用及读回 |
| 本地等待计算 | 已确认消息、角色和责任 → 等待 round 与截止时间 |
| 独立 alarm | 超时 round → 单一窗口展示；用户点击 → 正确网页会话 |
| 最小宿主与状态 | 登录隔离、窗口、最小持久状态 → 可恢复且不串身份的运行环境 |

开发顺序：网页身份/事件原型 → 消息事实与补偿 → 独立窗口 → 订单联系与网页必要操作 → 故障验收。不保留与当前范围无关的媒体、助手、更新、业务页或多账号桌面模块工作包。

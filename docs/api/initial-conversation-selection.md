# 账号刷新与初始会话选择

2026-10-31官方网页经ego刷新后先显示欢迎页，需显式点击会话。旧客户端`loadForActiveAccount`在没有选中会话时自动打开第一条；`openConversation`会加载历史，并可能向服务端发送已读回执。因此后台账号恢复不只是无副作用列表读取。

账号首次加载或刷新只更新列表，保留已有有效的显式选择；没有选择时保持空消息面板。用户点击会话、明确定位到会话的既有入口仍按原流程加载/已读。不会为了受控测试把某个真实gid写死进产品。

`startup-selection.test.ts`提取并执行main.ts的实际加载函数，只注入离线IPC/store环境。旧实现无选择时调用openConversation导致红；修复后无选择/已有选择两项均绿，列表正常更新且openConversation零调用。该验证不替代新包原生启动验收。

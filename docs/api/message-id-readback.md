# 界面上的服务端消息ID读回

消息操作区新增只读“消息ID”入口，直接显示当前UiMessage.message_id字符串；没有ID时明确显示尚无服务端消息ID，不把local_id、gid、客户昵称或订单号作为替代。此入口不发IPC、不触发网络、不修改发送状态，展示通过已有toast完成。

用途是将原生界面中同正文/发送者/时间的消息与官方协议中的服务端消息ID对应，补足第1轮仅显示级读回的证据缺口。显示ID不代表客户已读，unknown也不会由此变成confirmed。测试记录仅保留合成标记或ID摘要，不提交真实消息ID、客户正文和凭据。

本块只有直接字段展示及调用点；独立暂存快照typecheck与bundle验证，原生操作及跨端ID一致性需下一新包实测。

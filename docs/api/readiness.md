## 本轮已经补上的请求要素

- HTTP 方法、完整 host/path、Query、HTTP Header、Cookie/Auth 来源与浏览器自动字段。
- 完整请求体及嵌套结构、数组、JSON 字符串、字段大小写、原始类型、实际样本差异和可追溯来源。
- 动态 head、追踪/风控来源及静态源码指纹，不以真实 Cookie、Token 或客户标识作为固定示例。
- 响应结构、明确的成功/失败样本、受控写操作与读回；WebSocket 和 HTTP 发送兜底分列。
- TSim 来自当前拥有方和客户端源码的请求方法、鉴权、字段和错误语义；与携程浏览器实测分开。

准确请求数量、各接口样本和来源见[目录](README.md)。`requestElementsCaptured=true` 仅表示至少有一份 Header、ExtraInfo 和请求结构齐全的观测；不表示每个动态来源、所有分支、所有角色和宿主都已验证。机器目录的 `implementationReady` 保持 false，不自动用数量放行开发。

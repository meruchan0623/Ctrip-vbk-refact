# 撤回与引用的展示边界

2026-10-31。官方HTTP与SDK的msgtype1009控制消息携带recallMessageId；该ID保持字符串，经web-adapter、IPC与Rust展示DTO进入UI。原消息被撤回后不再出现在聊天行，回复引用显示“引用消息已撤回”，编辑器选中引用清除且不再出站quote_id，草稿保留。

新本地引用只记录已在当前会话查证的服务端目标ID，不复制原文；稀疏回显仅在发送者身份/角色相容时保留这份关联。历史quote旧字段混有自由文本与ID，缺明确来源时统一显示“引用内容不可用”，不猜测关联，也不显示可能已撤回的复制原文。此保守降级尚未完成官方所有历史引用格式对齐。

测试直接执行实际messageRow、composer、sendText、upsert，以及HTTP/SDK mapper→UI，另验证Rust DTO往返保持长ID精度。初次独立评审发现只提交UI会缺上游撤回字段，真实旧mapper反证仍泄文；补齐最小完整链后再进行独立快照验证，不借未暂存媒体/分页/订单实现。红绿原始证据位于/tmp/vbk-recall-quote-*.log、/tmp/vbk-recall-pipeline-*.log。

本次保护针对已同步到本地的撤回通知；未收到上游撤回事件时无法凭空知道内容已撤回。隐藏聊天原文不代表清除所有历史留存，留存策略及离线缺口见TSim迁移文档。第4轮包不含本修复，真实引用/撤回行为需下一轮包验收。

# 订单号展示与输入

2026-10-31。消息面板的订单输入校验与正文高亮支持官方已采证的 10 位、16 位数字订单号，并始终保留为字符串；不对 16 位值使用 JavaScript Number。11 位电话和嵌在更长数字串中的订单样式不得误识别。

实现为 `viewmodel.ts::ORDER_ID_RE/highlightParts`，现有订单查询与正文点击调用点继续使用这些函数；输入错误文案同步为“10 或 16 位数字”。回归保留既有 10 位/ICCID 判据，并覆盖16位、前后空白、11位电话、15/17位拒绝与完整词边界。真实订单来源证据见 `docs/api/evidence/2026-10-30/59-controlled-order-exact-search.json`；本改动不实现缺失的订单搜索接口参数。

# 分计划 05：当前范围验收

2026-10-30。只验收[当前总计划](00-master-development-plan.md)中的网页能力和独立强提醒。

1. 网页身份与消息：受控收发/回执、unknown 恢复、补偿完整性、角色与权限、失效与重新登录。
2. 通知与设置：具体网页版本的分类/内容/标读、保存失败与读回；普通网页提醒的权限和播放失败。
3. 订单联系：完整订单号、无结果/多结果/无权限、“详情 → IM 联系 → 正确会话”；不确认订单或发起退款。
4. 独立强提醒：阈值、轮次、不因已读清除、有效商家回复清除、窗口置顶但不抢焦点、隐藏/恢复及多条聚合。
5. 故障：主界面隐藏/最小化、网络中断、睡眠、重启、旧登录回调、显示器变化；恢复先对账。
6. 交付：选定平台的可运行候选包、必要签名/权限、脱敏日志与实际测量。不作没有基线的包体、工期或后台可靠性承诺。

macOS 仅在进入实际实现并通过同样矩阵后标记支持。没有自动更新/CDN、OCR、多账号桌面或全面业务页的验收关口。旧 G1–G5 大范围矩阵见[归档](../archive/desktop-baseline/plan/05-release-validation.md)，不再整体作为发布门槛。

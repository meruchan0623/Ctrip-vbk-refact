# Claude Artifact 前端原型删减清单

2026-10-30。用途：修改现有前端原型时，明确删除哪些页面、入口和设置，避免继续围绕旅游商家桌面版扩展功能。

本文依据[网页版范围决定](../decisions/2026-10-30-web-only-scope.md)、[订单联系流程](../research/2026-10-30-web-order-conversation.md)和[网页提醒调查](../research/2026-10-30-web-reminders.md)整理。尚未逐屏审查 Claude Artifact 原型；下列项目是删减要求，原型中存在时执行，不表示每项都已出现在原型里。

## 1. 原型最终保留什么

核心业务只保留三个部分：

1. **消息工作区**：会话列表、搜索、聊天、客户侧栏，以及目标网页实际提供的客服操作。
2. **通知中心**：分类、通知内容、未读数、已读和通知链接。
3. **订单联系入口**：按订单号找到订单，经“详情 → IM 联系”打开客户会话。

登录、退出、当前账号身份、客服工作状态和必要的个人设置继续保留。其他功能只有在目标网页有真实入口、且属于上述业务范围时才纳入。

**唯一例外：用户后续明确要求保留独立回复超时强提醒窗口。** 原型应表达该窗口和必要的开启、阈值、单次声音设置；这是本项目扩展，不标作网页原生能力。实现依据为[独立强提醒设计](../dev/03-strong-alert.md)。

## 2. 删除完整业务模块

下面这些模块连同导航、页面、弹窗、角标、快捷入口和演示数据一起删除。不要保留灰色菜单或“即将上线”占位。

| 删除模块 | 原型中需要一起移除的内容 |
| --- | --- |
| 首页 | 欢迎页、经营概览、业务指标、营销活动、推荐入口等 |
| 工作台 | 应用墙、我的常用、最近使用、业务线菜单墙、自定义快捷入口 |
| 事件 | 事件列表、待办事件、处理详情、事件角标和事件专属提醒 |
| 公告 | 公告列表、公告详情、公告未读角标 |
| 商服 | 商家服务大厅、课程中心、学习任务及其角标 |
| 产品 | 产品管理、上下架、库存、价格、资源维护等完整页面 |
| 数据 | BI、经营报表、销售图表、统计筛选和导出 |
| 点评 | 点评管理、回复点评、评分分析等完整页面 |
| 完整订单管理 | 待确认、核单、退款、取消、改期、配送、凭证维护、批量操作、财务金额分析和导出等 |

即使官方网页版有这些业务页面，也不属于本项目本轮范围；“网页版有”只是必要条件，不表示全部照搬。

## 3. 订单模块缩减为“联系客人”

**不能把订单入口整个删除。** 主动联系客人是必须保留的流程。

原型可用“订单联系”入口或消息页内的入口承载，流程应完整：

```text
输入完整订单号 → 查询 → 核对匹配结果
                         ↓
                   操作栏「详情」
                         ↓
                 联系人旁「IM 联系」
                         ↓
                  打开客户网页会话
```

| 保留 | 删除 |
| --- | --- |
| 完整订单号输入、查询、加载和失败状态 | 复杂订单业务筛选和大规模订单管理表格 |
| 足以辨认订单的结果摘要、无结果/多结果状态 | 确认、核单、退款、退订、改期、批量确认、导出等按钮 |
| 结果操作栏“详情”及详情中的“IM 联系” | 详情内与联系客人无关的交易操作和维护表单 |
| 打开会话后的客户身份、会话标题和输入框 | 用“联系携程客服”代替“IM 联系” |

原型可简化订单展示，但不能省略核对目标的步骤，也不能让“查询订单”直接等同于“已联系客人”。真实网页的“IM 联系”会打开可联系客户的网页标签；原型中至少表达该跳转和结果。

消息页另有“输入订单号 → 搜索已有会话 → 会话历史 → 开始聊天”的路径，也可以保留。它与从订单详情主动发起联系是两条流程，不能合并为一个声称必定能新建会话的搜索框。

## 4. 保留独立强提醒，删除其他扩展提醒

独立窗口保留超时会话、等待时长和“打开会话”；置顶但不抢焦点，默认阈值 30 秒。可播放一次提示音，不循环。关闭只隐藏当前等待轮次，不当作已回复；服务端确认有效商家回复/结束/转出后才清除。它不依赖专用强提醒后端接口，也不能在原型中标成已开发或已验收。

| 删除的界面/交互 | 一起删除的设置 |
| --- | --- |
| 反复抢置顶、全屏强制展示、强制确认 | 置顶等级和全屏强制提醒策略；保留独立窗口正常置顶显示 |
| 循环播放、逐级升级、贪睡、稍后提醒 | 循环间隔、重复次数、L0–L4 升级规则、贪睡时长 |
| 托盘未读预览窗口、任务栏/托盘闪烁演示 | 托盘预览、任务栏闪烁、桌面专属提醒偏好 |
| 通知分类“特别关注”星标和对应右键菜单 | 特别关注、取消特别关注、分类自定义提示音 |

当前新版网页虽然保留超时计算代码，但没有承接对应强提醒事件；不能据此声称网页原生已支持独立窗口。当前按用户后续要求，由本项目新增独立窗口，其余提醒扩展仍删除。在线后的短时观察不能证明所有账号和配置都没有该能力。

**普通提醒继续保留**：消息/通知未读数、页面横幅、浏览器通知、失焦标题提示和单次提示音。浏览器通知需要权限，声音可能受自动播放限制；不要在原型中承诺页面关闭后仍持续提醒。

## 5. 删除桌面专属页面与设置

原型中若存在下列内容，移除其入口、设置项和弹窗：

- 多账号桌面标签栏、账号窗口池、独立业务窗口、内置浏览器地址栏和标签管理。
- 全局快捷键、开机启动、关闭后驻留托盘、主窗口置顶等额外桌面设置；独立 alarm 的置顶与保持在可见工作区属于窗口必需行为，保留。
- 独立截图工具、全屏截图遮罩、OCR、桌面本地纠错工具及模型下载管理。
- 客户端自动更新、更新通道、安装包下载、版本回滚和桌面更新弹窗。
- 代理/PAC、网关切换、环境切换、GPU 开关、桌面运行时和传输模式选择。
- 桌面崩溃上报配置、客户端调试面板及面向开发者的诊断控制台。

不删除正常的登录和当前账号身份展示。取消的是桌面多账号管理交互，不表示聊天中可以省略账号归属。

## 6. 容易误删的内容

| 不要误删 | 与被删除模块的区别 |
| --- | --- |
| 消息里的客户信息、会话成员、订单摘要 | 不等于完整客户管理或完整订单管理页面 |
| 网页聊天中已有的产品推荐/产品卡片 | 不等于独立“产品管理”模块；仍需对应网页入口支持 |
| 通知中心的“产品通知、订单通知、财务通知”等分类 | 删除独立产品/订单/数据模块，不代表这些通知分类一起删除 |
| 通知卡片中的链接 | 可以表达跳转官方业务网页，不需要在原型里重建对应业务系统 |
| 消息、未读角标、普通横幅与单次声音 | 网页既有提醒保留；独立强提醒另作为唯一扩展保留 |
| 当前网页已有的个人资料、上班时间、快捷回复、自动答复、自动翻译 | 与桌面通用设置分开；不补造网页没有的设置项 |
| 网页已有的会话置顶/标记入口 | 会话标记与被取消的“通知分类特别关注”不同；不额外承诺跨设备同步 |

结束、转移、邀请、评价、总结、上传等会话内功能，应按具体目标网页和账号实际开放的入口保留。证据不足时先不在原型中作可用承诺，不因桌面包中有同名代码就补齐。

## 7. 可直接交给 Claude Artifact 的修改要求

```text
请对现有前端原型做范围删减，保留现有视觉风格，只保留消息、通知、订单联系入口，以及登录、客服状态和网页已有的必要个人设置。

删除首页、工作台、事件、公告、商服、产品管理、数据报表、点评和完整订单管理，并一起删除其导航、角标、快捷入口、弹窗和演示数据，不保留“即将上线”占位。

订单不能全部删除：保留输入完整订单号、查询和核对结果，再点击操作栏“详情”，进入详情点击联系人旁“IM 联系”，打开客户网页会话。另保留消息页按订单号搜索已有会话、查看历史并“开始聊天”的流程，不把两者混为一谈。

保留一个独立回复超时强提醒窗口：默认 30 秒，显示待回复会话、等待时长和打开会话；置顶但不抢焦点，可播放一次声音。保留必要的开启、阈值和声音开关。关闭只隐藏当前轮次，已读和点击发送不当作已回复；服务端确认有效回复/结束/转出才清除。此窗口是本项目新增能力，标注待实现，不冒充网页原生功能。

删除反复抢置顶、循环声音、提醒升级、贪睡、托盘预览及其设置。删除通知分类“特别关注”和自定义分类声音。普通未读数、页面横幅、浏览器通知和单次声音继续保留。

删除桌面多账号标签、内置业务浏览器、全局快捷键、开机启动、截图/OCR/本地纠错、自动更新、代理网关和开发调试设置。

不要误删消息里的客户侧栏、订单摘要、网页已有的产品推荐，也不要删除通知中心的订单通知、产品通知等分类。除明确保留的独立强提醒窗口外，网页没有或未确认开放的能力不新增。

删减后检查所有剩余按钮、菜单和空状态，确保没有死链接、失效跳转或已删除模块的残留入口。
```

## 8. 删减后的检查清单

- [ ] 主要业务入口只剩消息、通知和必要的订单联系入口。
- [ ] 登录、当前账号、客服状态和网页个人设置仍可找到。
- [ ] 从订单号到“详情 → IM 联系 → 客户会话”的流程完整。
- [ ] 搜索已有会话与主动联系客人的流程表达清楚。
- [ ] 保留独立强提醒窗口及必要的开启、阈值、单次声音设置，并标明待实现。
- [ ] 没有循环声音、分级升级、贪睡、托盘预览或反复抢置顶。
- [ ] 普通未读、横幅、浏览器通知和单次声音没有被误删。
- [ ] 消息侧栏、通知分类没有因顶层模块删除而一起消失。
- [ ] 被删功能的导航、角标、弹窗、演示数据和跳转全部清理。
- [ ] 除用户明确保留的独立强提醒窗口外，没有超出目标网页实际能力的承诺。

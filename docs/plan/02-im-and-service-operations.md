# 分计划 02：网页 IM 与必要业务

2026-10-30。对应[总计划](00-master-development-plan.md) P1/P3。

- 实现目标网页已验证的消息列表、会话、收发回执、历史、已读和断线补偿；未知发送结果不盲目重试。
- 保留网页开放的客服工作状态与个人设置；服务端成功后回读。
- 会话列表“处理中 / 已完成”选项卡；右键置顶为本地行为，颜色标记使用已实测的 `setWorkSheetStar`（0清除、1橙/2绿/3蓝/4紫/5粉），见[实测报告](../research/2026-10-30-browser-api-validation.md)。
- 实现通知分类、内容和标读，以及网页已有的普通提醒；标读不等于已回复。
- 保留订单管理“详情 → IM 联系 → 网页会话”，与消息页“订单号搜索已有会话”分开验收。
- 评价/结束/成员操作/附件/官方翻译等仅按实际网页版本与角色开放；单个受控成功样本不代替权限、超时和恢复验收。颜色标记复用名字带Star的接口，不增加独立星标功能。
- 为独立强提醒输出同一份消息、角色、责任和确认事实，不另建提醒连接。

详细边界：[网页 IM](../dev/10-im.md)、[订单入口](../dev/04-business-pages.md)、[接口复查](../research/2026-10-30-missing-apis.md)。原桌面传输/界面全量工作包见[归档](../archive/desktop-baseline/plan/02-im-and-service-operations.md)。

# 分计划 03：独立强提醒窗口

2026-10-30。对应[总计划](00-master-development-plan.md) P2。它是唯一网页之外扩展。

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| A1 | 接收网页消息/会话事实 | 身份、角色、代次、回执及补偿边界可靠，不依赖额外提醒 API |
| A2 | 等待 round 与 30 秒期限 | 连续客户消息取本轮起点；确认有效商家回复/结束/转出才清除 |
| A3 | 单例 alarm | 主界面最小化仍显示；置顶、不抢焦点、可定位正确会话 |
| A4 | 隐藏与恢复 | 只抑制当前 round/version；断网/睡眠/重启先对账，旧身份不能补响 |
| A5 | 受控验收 | 按[设计矩阵](../dev/03-strong-alert.md#7-原型与验收)逐项留证 |

不开发通用业务页、独立普通横幅、托盘 tooltip、持续声音或分级升级。窗口方案为待实现设计，不能引用旧客户端原生窗口作为已通过证据。

原方案见[归档](../archive/desktop-baseline/plan/03-shell-business-notification.md)。
